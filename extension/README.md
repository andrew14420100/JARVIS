# JARVIS Brain

Estensione VS Code privata del progetto JARVIS. Espone i comandi visti nel workflow di riferimento:

- `Jarvis: Apri`
- `Jarvis: Griglia del Cervello`
- `Jarvis: Radar`
- `Jarvis: Radar Ads`
- `Jarvis: Installa il cervello`

La memoria vive in Markdown nella cartella `brain/` ed e' compatibile con Foam tramite wikilink `[[...]]`.
